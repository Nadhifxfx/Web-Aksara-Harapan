🧩 Game Petualangan 2D: Aksara Harapan
Sebuah game sekaligus website edukasi yang dirancang untuk membantu pemain belajar Bahasa Isyarat Indonesia (BISINDO) melalui pengalaman petualangan interaktif dan visual.

🚀 Fitur Utama
🎮 Mode Petualangan Edukatif
- Jelajahi dunia 2D yang interaktif sambil belajar Bahasa Isyarat.
- Setiap level mengenalkan huruf, kata, atau ekspresi baru dalam BISINDO.
- Sistem quest dengan tantangan berbasis gestur.
- NPC (Non-Player Character) memberikan penjelasan dan latihan interaktif.

🧠 Terintegrasi dengan AI (Gemini AI)
- Penjelasan otomatis tentang arti dan konteks gerakan isyarat.
- Feedback real-time atas gestur pemain (benar/salah + saran perbaikan).
- Pembangkitan kuis edukatif secara dinamis berdasarkan progres pemain.
- Dialog NPC yang cerdas dan adaptif menggunakan API Gemini.

🏆 Sistem Level & Progres Pemain
- Pengumpulan poin dari setiap misi dan latihan berhasil.
- Fitur pencapaian (achievement) untuk mendorong motivasi belajar.
- Penyimpanan progres pemain menggunakan sistem database ringan.

📚 Modul Belajar Bahasa Isyarat
- Koleksi gestur huruf dan kata lengkap dengan deskripsi visual.
- Mode latihan berulang untuk mengasah pemahaman.
- Tampilan gestur animatif berbasis sprite 2D agar mudah diikuti.

🛠️ Teknologi
- Game Engine: Unity 2D
- Bahasa Pemrograman: C#
- Backend & API Integrasi: Python (Flask)
- Kecerdasan Buatan (AI): Gemini Pro / Gemini Pro Vision API
- Metode Pengembangan: Rapid Application Development (RAD)
- Desain Visual & Asset: Adobe Illustrator, Aseprite

🌟 Tujuan Utama
- Meningkatkan minat belajar Bahasa Isyarat melalui media game interaktif.
- Memberikan pengalaman belajar yang menyenangkan, inklusif, dan adaptif.
- Memanfaatkan AI (Gemini) untuk menciptakan pembelajaran yang kontekstual dan dinamis.
