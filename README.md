# **🧩 Website Aksara Harapan**
Sebuah platform edukatif sekaligus showcase dari proyek game **Rancang Bangun Game Petualangan 2D untuk Edukasi Bahasa Isyarat Menggunakan Metode Rapid Application Development (RAD)**, yang dirancang untuk membantu pengguna mempelajari Bahasa Isyarat Indonesia (BISINDO) secara interaktif dan menyenangkan.

## 🚀 Fitur Utama
Website ini berfungsi sebagai pusat informasi, dokumentasi, dan portal pembelajaran yang terhubung langsung dengan **AI Gemini**, menghadirkan pengalaman belajar yang adaptif dan berbasis teknologi terkini.

###🎮 Mode Petualangan Edukatif
- Menjelajahi dunia 2D penuh warna dengan misi-misi pembelajaran BISINDO.
- Setiap level memperkenalkan huruf, kata, atau ekspresi baru melalui interaksi visual dan naratif.
- Sistem quest dan challenge berbasis gestur untuk meningkatkan daya ingat pemain.
- Karakter NPC (Non-Player Character) memberikan petunjuk, latihan, dan kuis interaktif sepanjang permainan.

###🤖 Terintegrasi dengan Gemini AI
- Chat Edukasi Interaktif – Pengguna dapat bertanya langsung tentang arti dan konteks bahasa isyarat, dijawab secara cerdas oleh Gemini.
- Analisis Gambar Gestur (Vision) – AI mampu mengenali dan memberikan umpan balik terhadap gestur tangan yang diunggah pengguna.
- Kuis Dinamis dan Adaptif – Gemini menghasilkan pertanyaan berdasarkan kemajuan belajar pengguna.
- Dialog NPC Cerdas – Setiap percakapan dalam game dihasilkan secara kontekstual oleh Gemini agar terasa alami dan personal.

###📚 Modul Belajar Bahasa Isyarat
- Koleksi lengkap huruf, kata, dan ekspresi BISINDO dengan deskripsi teks dan ilustrasi gestur animatif.
- Mode Latihan Berulang untuk memperkuat daya ingat pengguna.
- Tampilan sprite 2D animatif mempermudah pengguna dalam meniru gerakan tangan secara akurat.

###🛠️ Teknologi yang Digunakan
- Game Engine: Godot Engine
- Bahasa Pemrograman: GDScript
- Kecerdasan Buatan: Gemini Pro & Gemini Pro Vision API
- Metodologi: Rapid Application Development (RAD)
- Desain Visual & Aset: Adobe Illustrator, Aseprite
- Frontend Website: HTML, Tailwind CSS, JavaScript

###🌟 Tujuan Utama
- Mengedukasi masyarakat luas mengenai Bahasa Isyarat Indonesia dengan cara yang menarik dan mudah diakses.
- Menumbuhkan empati dan inklusivitas melalui media game interaktif.
- Mengintegrasikan AI untuk menghadirkan pembelajaran kontekstual dan personal.
- Mendorong inovasi pembelajaran berbasis teknologi yang ramah bagi pengguna tunarungu maupun umum.
